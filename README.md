# RISI Service Desk

**Информационная система учета заявок и услуг**  
Для ООО «Рубан и Старков Индастриз»

## Описание проекта

RISI Service Desk — это веб-приложение для автоматизации процессов приема, обработки и учета клиентских заявок на услуги компании в сферах:
- Веб-разработка
- Дизайн
- Системное администрирование
- Внедрение информационных систем

## Функциональность

### Заявки
- Просмотр списка всех заявок
- Фильтрация по статусу (Новая, В работе, Выполнена, Закрыта)
- Добавление новой заявки
- Смена статуса заявки
- Удаление заявки

### Клиенты
- Просмотр списка клиентов
- Добавление нового клиента
- Удаление клиента

### Услуги
- Просмотр списка услуг (название, стоимость, срок)
- Добавление новой услуги
- Удаление услуги

## Технологии

- HTML5
- CSS3 (адаптивный дизайн)
- JavaScript (ES6+)
- LocalStorage для хранения данных

## Установка и запуск

1. Скачайте все файлы проекта
2. Откройте файл `index.html` в любом современном браузере
3. Данные сохраняются автоматически в localStorage

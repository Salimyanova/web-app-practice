## Описание проекта

Веб-приложение, разработанное в рамках учебной практики. Реализует функционал информационной системы для учета данных.

## Технологии

- HTML5
- CSS3
- JavaScript (ES6+)

## Структура проекта

- `index.html` - главная страница
- `style.css` - стили оформления
- `script.js` - логика приложения

## Запуск

Открыть файл `index.html` в любом современном браузере.
